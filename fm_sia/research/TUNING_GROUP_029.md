# 029 组 · 稳定轴位的幅值可靠性加权

029 从 012 极坐标条件 FNO 出发，按目标幅值的饱和平方权重汇总稳定轴位余弦误差。五项调参直接继承 029；相对基础 FM-SIA，依次继承 005 的术前方向矩直接 SIA 分支、009 的条件 FNO、012 的非负幅值与双角度相位，以及 029 的轴位加权机制。

**验证。** 初始方案、029_2、029_3、029_4 通过完整近邻。029_5 单独采用 0.25 D 饱和尺度，八项保护与幅值实质改善线全部通过。均按相同三折、同一验证图像 MAE 选优 epoch 比较；两端独立复算选出相同的唯一候选。[测试前冻结提交](https://github.com/LQWWHEN/Corntopo/commit/f4fe78d30b7690aa18658a916d4cce1ac8a8326e)

**测试。** 029_5 回载原验证权重完成一次三折评估。相对基础 FM-SIA，术后图像四项与 SIA 幅值、向量、稳定轴位均改善。相对 012，图像 MAE 和 RMSE 改善，PSNR 与 SSIM 略低；幅值 MAE 三折均退化，幅值 RMSE、向量 RMSE 和稳定轴位 MAE 的三折均值亦退化。验证幅值改善未在测试中复现，本组结束，继续以 012 为新机制的直接比较基准。

备注：组内五次预算已用完。初始方案与五个变体的临时权重均已清理。定量、逐折结果与图像保存在私有报告中。
