# CornTopo 001–050 阶段总结

截至 050，50 个初始方案和 109 个组内调参配置完成验证，23 个调参组结案。10 个迭代配置有实际测试记录，另有 000 基础 FM-SIA 对照。逐轮方法、直接父模型与组内决策见[迭代索引](README.md)。

## 三项任务的模型选择

以术后图像、SIA 幅值和轴位为联合目标，优先推荐 012。005 从共享术前编码提取二阶方向矩，009 以临床 FiLM 和多尺度图像特征驱动 Fourier 速度场，012 在 009 上分别读出非负幅值和双角度相位。完整测试的联合模型中，012 的幅值 MAE、幅值 RMSE 和稳定轴位 MAE 最低，图像四项指标均优于基础 FM-SIA。

图像优先时，010 的四项图像指标在联合模型中领先。016 的向量 RMSE 在联合模型中最低，按眼别计算的训练折均值向量在该指标上仍优于 016。004 为仅预测幅值的消融。各模型的适用任务和历史测试流程见[前期阶段记录](STAGE_000_030.md)。

## 各研究方向的结果

| 方向 | 本阶段的判断 |
|---|---|
| 几何与眼别 | 010 在 009 上引入可逆镜像，图像和 SIA 均有收益。把同一策略移到 012 得到 016，向量误差下降，幅值和轴位误差上升。D4 和球镜偏移增强未获得同等支持。 |
| 临床字段 | 加入术前散光向量分量、移除 Kmax 均未取得新的测试资格。四字段设置应保留为后续对照。 |
| 条件融合 | 空间注入、跨尺度交换与多尺度方向读出曾接近正式门槛。在 050 的同权重对照中，学习字段权重有时改善幅值，有时改善轴位，整体未通过联合筛选。 |
| SIA 参数化 | 直接术前方向读出及非负幅值与周期相位分解的收益延续至测试。分支拆分、浓度估计与分位数预测尚未取得新的测试优势。 |
| 多任务平衡 | 梯度平衡、方向系数共享和梯度投影揭示图像与 SIA 的取舍。043 初始方案保护住全部指标，实质改善不足。 |
| 速度网络与流状态 | 条件 FNO 是可靠的直接对照。U 形谱算子、卷积 U-Net 及余弦模态等尝试有局部收益。049 的外带改善在三折方向一致，整体 SSIM 和幅值仍限制入选。 |
| 图像及轴位损失 | 形态、梯度和物理量纲损失未带来新的联合测试优势。029_5 的验证幅值收益在冻结测试中反向，图像 MAE 则有改善。 |
| 表示与生成 | 015 的连续向量排序改善测试图像 MAE，幅值和方向弱于 012。自回归预测仍待独立对照。 |

## 后续假设

1. 固定 012 编码器及输入，单独检验原坐标和镜像坐标下的方向读出，按眼别与术前散光强度分析幅值和轴位。
2. 以 040 为直接对照，检验不同空间尺度的平均功率与细节误差能否同时降低，并以 012 保护三项输出。已准备的 051 属于该方向。
3. 对 050 使用配对的学习与等权推理，在独立患者或预留折上验证字段贡献与病例形态的关系，再决定是否扩大模型或增加条件路径。
