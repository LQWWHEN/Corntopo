# 054 · 训练折初始化对极坐标读出的贡献

直接父模型是 012，来源版本 `a8bd0232cf64b6f1f12cdf7f8e05e7e4f0d221f8`。012 同时改变了输出参数化、监督和初始化。054 单独撤去读出层两个偏置的训练折拟合值。从相同种子构建父模型与消融模型，除两个偏置外，所有初始张量逐项相同。

## 研究问题

方向回归可在圆上建模；以余弦衡量相位误差时，训练样本平均单位向量的方向也是最优常数方向。幅值 L1 的最优常数解是训练中位数。012 恰好从这两个常数出发。054 检验最终个体预测有多少依赖这一起点。009 使用 Cartesian 读出，024 拆分隐藏层，026 替换轴位距离，029 调整稳定标签权重；检索历史配置及调参项后，均未隔离初始偏置。[Prokudin、Gehler 与 Nowozin](https://arxiv.org/abs/1805.03430)

## 配方与比较

将原始幅值偏置与双角度相位偏置都初始化为 0。经 softplus 解码，起始幅值为 ln(2) D，物理轴位为 0°。后续两项都可学习。相对基础 FM-SIA，累计保留 005 的术前方向矩直接读出、009 的条件 FNO、012 的幅值与周期轴位分解及相应的 L1 和余弦损失。尺度、容量、四项临床条件与其余优化参数沿用 012。

主要配对比较针对 012 各折的选优结果，并核对首个验证 epoch 至所选 epoch 的幅值和稳定轴位变化，区分早期收敛与最终预测差异。完整评价涵盖术后图像四项指标、SIA 幅值两项、双角度向量及稳定轴位，报告覆盖率。原前三折各 200 epoch，验证图像 MAE 选优。新方案的组末筛选和调参预算遵循[本阶段协议](ITERATION_052.md)。

## 备注

本消融估计幅值和相位初始化作为一个模块的联合贡献。

054 三折验证完成。相对 012，撤去拟合偏置后幅值 RMSE 在三折均升高，稳定轴位均值略改善。达到完整近邻，初始配置未获测试资格，已清理权重并进入组内调参。
