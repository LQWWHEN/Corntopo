## 完整输出及评估要求

后续候选必须同时提供术后图像、SIA幅值和轴位。优先使用项目现有双角度
物理向量 q=(X,Y)，幅值为 sqrt(X²+Y²)，轴位为
0.5*atan2(Y,X)（转为角度后模180°）。不能对该向量直接使用普通向量角度。
轴位误差应按180°周期计算：min(|预测轴位-GT轴位|,180°-|预测轴位-GT轴位|)。
预测和GT轴位先归一到[0,180)。分别报告幅值MAE/RMSE、轴位周期误差和向量误差。

零幅值的轴位未定义；近零幅值的轴位不稳定。必须在实验前声明处理/阈值、
有效样本数与覆盖率，不能把未定义轴位记为零误差，也不能根据测试结果删样本。
旋转/翻转增强必须同步转换向量和方向性临床输入。

## Checkpoint策略（2026-11-14更新）

用户已明确授权实验期间临时保存checkpoint。正式验证训练添加
`--save_checkpoints --validation_only`；按预设门槛和验证指标冻结选择后，
运行`cddpm/test_saved_run.py --run_dir TRAIN --output_dir TEST`。
该入口先检查全部折的配置、划分、选择epoch、归一化及回载验证指标，再创建
测试loader；直接测试原训练权重，不再为恢复权重重复训练。

测试结果验收通过后，运行`cddpm/checkpoint_lifecycle.py --run_dir TRAIN
--test_dir TEST --audit_record AUDIT_JSON --outcome tested`。清理只作用于本轮
实验目录的临时权重及优化器快照，写入零残余验收记录。
验证未入选的试验在归档决策后使用`--outcome rejected`清理，不强行执行测试。
异常中断可临时保留恢复文件；恢复或放弃处理完成后清除。除非用户另行要求，
完整一轮结束时不保留任何checkpoint，也不把权重打入归档。

维护训练入口不带`--save_checkpoints`时仍支持内存选优，用于短工程检查。
历史重训费用与来源记录保持原样；旧checkpoint哈希不代表仍有权重文件。
指标、逐例预测、图像、日志、配置和源码继续保留。

## 图像报告

图像表必须同时列PSNR（dB）、SSIM、RMSE，并保留MAE。统一取原128×128
预测的共同有效像素域，训练折全局尺度归一化，指标计算不做显示裁剪。
PSNR按每折有效像素MSE计算，归一化峰值范围为1；三折分别计算后汇总均值和
总体标准差，不能用平均RMSE反推平均PSNR。原单位RMSE另注明`RMSE_raw`。
验证、测试分别汇报，图像与SIA表分开；可视化仍为128×128 turbo。

## 无训练的术前图保持对照

`cddpm/evaluate_persistence.py --reference_run RUN --output_dir OUT`直接将术前
FRONT作为术后预测，复用参考实验的患者划分、训练折归一化和统一图像指标。
验证与测试分别汇总PSNR、SSIM、RMSE、MAE，并独立核对有效像素误差。
预测不读取术后图或术后mask；后者只用于评估共同有效区域和绘图。
它用于量化模型相比保持术前形态的增益，不输出SIA，也不是完整联合任务模型。
该对照没有训练、拟合参数或checkpoint，不计为调参轮次，不改变已冻结试验
的选优门槛。输出含逐例图像和数据来源，必须保留在私有目录。
